Plugin della demo

I plugin predefiniti vengono scaricati, installati e verificati automaticamente. Un errore di un plugin non impedisce l'avvio degli altri. Aggiungi il pacchetto desiderato al progetto e configurane gli input.

Gli eventuali servizi LLM richiedono modelli, endpoint o chiavi personali. Consulta il README per le condizioni della dipendenza esterna llm_eval, scaricata soltanto nei volumi locali.
